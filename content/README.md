# Content Directory

This folder holds all markdown content for your site.
It can be synced to Obsidian Vault or Google Drive for AI-agnostic backup.

## Structure

```
content/
├── README.md          ← You are here
├── bio.md             ← Your artist bio (editable)
├── artworks/          ← Artwork descriptions (one per file)
│   ├── ocean-at-dusk.md
│   └── ...
└── blog/              ← Future blog posts
```

## How to Use

1. Edit any `.md` file with your content
2. Push to GitHub → auto-deploys to Vercel
3. Sync this folder to Obsidian or Google Drive for backup

All content stays in standard Markdown — works with any tool, no vendor lock-in.
